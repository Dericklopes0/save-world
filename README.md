# save-world
Aplicação web para gerenciamento de campanhas sociais, controle de doações e acompanhamento de metas de arrecadação. Desenvolvida com HTML e CSS.

## Estrutura do projeto

```
save-world/
├── index.html          página inicial (entrar, criar conta, campanhas em destaque)
├── css/
│   └── style.css       estilo de todo o site
├── fotos/              fotos do mural da página Sobre
└── html/
    ├── sobre.html
    ├── tutorial.html
    ├── campanhas.html
    ├── campanha-cestas.html, campanha-abrigo.html, campanha-agasalhos.html
    ├── materiais.html
    ├── ajuda.html
    ├── doar.html
    └── voluntarios.html
```

## Funcionalidades
- Página inicial com entrada e criação de conta de doador
- Lista de campanhas com barra de progresso, prazo e histórico de doações
- Materiais necessários: o que ainda falta em cada campanha
- Formulários para doar e para ser voluntário, com validação nativa do HTML
- Página Sobre com vídeo e mural de fotos
- Ajuda com dúvidas frequentes e contato para organizações beneficentes

## Tecnologias
HTML5 e CSS3 (Grid, Flexbox, media queries e animação de barra de progresso).

## Como executar
Abra a pasta no VS Code e abra o index.html (Live Server ou direto no navegador).
